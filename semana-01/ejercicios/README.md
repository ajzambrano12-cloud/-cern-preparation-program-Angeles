# Ejercicios y Prácticas Autónomas — Semana 01

Espacio destinado a pruebas de conexión, notas de configuración de entorno y exploración inicial del portal de datos abiertos del experimento CMS (CERN Open Data).

### Contenido y actividades prácticas:
* **Exploración del portal CMS Open Data:** Navegación por registros de datos primarios de colisiones protón-protón del Run 1 del LHC.
* **Inspección de metadatos:** Análisis de la nomenclatura de tres niveles para el dataset /SingleMu/Run2012B-22Jan2013-v1/AOD.
* **Configuración del entorno de trabajo:** Verificación de terminal local y primeros comandos de Git para el portafolio.
