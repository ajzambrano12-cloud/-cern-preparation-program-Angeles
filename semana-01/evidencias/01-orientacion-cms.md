### 1. ¿Cómo está organizado el CMS Open Data Workshop 2024?
Se estructura en pre-ejercicios obligatorios que son previos al evento con un cronograma de 4 días con dos bloques diarios: mañanas dedicadas a "hackathon" que son proyectos prácticos con apoyo de facilitadores y tardes con lecciones teórico-prácticas como triggers/luminosidad, selección de eventos, modelado de fondo, incertidumbres experimentales, inferencia estadística, cerrando con una sesión de recursos y encuesta final.

### 2. ¿Qué herramientas/tecnologías identificaste?
- Docker (contenedores) para el entorno de trabajo
- ROOT (C++) y Python para el análisis de datos
- Formato NanoAOD (datos Run 2 de CMS)
- Portal CERN Open Data para acceso a los datasets
- Git/GitHub para control de versiones y materiales del curso

### 3. ¿Qué parte del entorno o documentación te resultó nueva?
El uso de contenedores Docker preconfigurados para reproducir el entorno de análisis de física de partículas, y el formato NanoAOD como forma reducida y accesible de los datos crudos de CMS.

### 4. ¿Tuviste alguna dificultad al navegar por los recursos?
La documentación está distribuida en múltiples sitios enlazados (Indico, GitHub Pages, guías de Carpentries), lo que exige saltar entre varias páginas para reconstruir la secuencia completa del taller.
