# CERN Preparation Program
## Nombre del programa
Programa de Preparación CERN

Fortalecer mis conocimientos técnicos y prácticos para participar 
en el programa, mejorando mi capacidad de resolución de problemas 
y trabajo con nuevas tecnologías.

- Programación (ej. Python, C++)
- Estructuras de datos y algoritmos
- Control de versiones (Git/GitHub)
- Trabajo en equipo y documentación técnica
