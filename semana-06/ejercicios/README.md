# Ejercicios y Prácticas Autónomas — Semana 06

Espacio destinado a esquemas metodológicos, notas de lectura crítica y síntesis de recursos de investigación científica.

### Contenido y actividades prácticas:
* **Metodología de investigación (Elsevier Researcher Academy):** Notas sobre delimitación del problema científico, formulación de preguntas investigables y evaluación de relevancia académica.
* **Método de las tres pasadas (S. Keshav):** Esquema de lectura crítica y evaluación de las 5 Cs (Categoría, Contexto, Corrección, Contribuciones y Claridad).
* **Fichas de análisis bibliográfico:** Resúmenes analíticos del artículo de referencia sobre el formato CMS NanoAOD (*Rizzi et al., EPJ Web of Conf. 214, 2019*).
