# Semana 03 — Trabajo Científico

Actividades de la tercera semana del programa (14 al 18 de septiembre de 2026):

- **ROOT y NanoAOD:** Uso de Docker para CMS Open Data, introducción a NanoAOD y análisis con Python usando `uproot`.
- **Trabajo colaborativo:** Práctica con ramas en Git, resolución de conflictos y creación/revisión de Pull Requests en GitHub.
- **CV Técnico Internacional:** Elaboración de CV técnico en inglés en formato Europass orientado a oportunidades en el CERN.

## Estructura
- `ejercicios/`: Cuadernos y scripts de análisis.
- `evidencias/`: Documentación, capturas y entregables de la semana.
