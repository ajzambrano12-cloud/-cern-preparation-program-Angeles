# Ejercicios y Prácticas Autónomas — Semana 03

Espacio destinado a scripts de prueba, exploración de datos en formato ROOT y NanoAOD, y ejercicios de preparación para el análisis científico.

### Contenido y actividades prácticas:
* **Lectura de archivos ROOT:** Pruebas de acceso columnar y deserialización de estructuras TTree mediante uproot.
* **Manipulación de arreglos irregulares:** Ejercicios básicos con wkward-array para el manejo de colecciones de partículas por evento.
* **Exploración de ramas de NanoAOD:** Inspección de variables cinemáticas de muones y electrones (pt, eta, phi, mass).
