# Ejercicios y Prácticas Autónomas — Semana 05

Espacio destinado a borradores preparatorios de correspondencia científica, guías de entrevista en inglés técnico y notas de autoevaluación.

### Contenido y actividades prácticas:
* **Borradores de carta de motivación:** Estructuración de párrafos formales para la postulación al CERN Summer Student Programme bajo el estándar del British Council.
* **Preparación de entrevistas:** Banco de preguntas y respuestas técnicas (*English for Interviews — You're Hired*).
* **Plan de fortalecimiento continuo:** Diagnóstico de competencias lingüísticas (progresión hacia B1/B2) y técnicas.
